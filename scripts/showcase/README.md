# Original showcase assets

Run `node --import tsx scripts/generate-showcase.ts` from the repository root. The generator creates six original GLBs under `examples/playground/assets/showcase/`, plus the typed summary in `metadata.ts`. Nothing is downloaded. Geometry, wood grain, leaf veins, surface pores, brushed metal, ceramic and landscape textures are generated by the source files in this directory.

The first run builds all six kits. Later runs compare a source fingerprint and output sizes, and return immediately when the generated files are present. Use `--force` to regenerate regardless of the receipt. Unchanged file bytes are not rewritten. Generated GLBs are self-contained and may be compiled with the regular Stream3D compiler.

Static parts are batched by material inside each animated assembly. Door hinges, the reactor rotor, two tree crowns, coral branches and the tracking lamp head remain separate animation targets. This keeps the kit primitive count small while retaining actual mechanical and botanical movement. The compiler receives this already-batched hierarchy and does not need to alter its structure.

`metadata.ts` reports actual source bytes, bounds, texture resolutions, animations and material names. `originalUniqueTriangles` counts each authored geometry once before batching; `uniqueTriangles` counts the emitted geometries after batching, which also bakes a small number of repeated bolts into their material assembly. `drawnTriangles` counts one occurrence of every rendered mesh in a single kit. `primitiveCount` describes the source GLB primitives, not a guarantee of GPU draw calls under every transparency or rendering policy.

The original geometry exceeds 400,000 unique triangles across the six kits. Landscape relief, curved roofs, corrugations, helical pipes, leaf curvature and branching coral provide the detail. The generator checks this geometric threshold and a 10 MiB source threshold; it never appends filler bytes. High-resolution source assets are intended to exercise compilation and progressive loading, not to be fetched directly by the browser demo.
